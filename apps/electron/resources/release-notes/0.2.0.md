# v0.2.0 - Agent Compose in Zo

## Features

- **Native Agent Compose agents** Connect multiple servers and use their existing agents in Zo conversations. Discover agents and provider models automatically, create and edit agents in a dedicated settings page, and test server connections before saving.
- **Let Zo draft agents** Use an existing Zo model connection to draft an agent's name, description and system prompt. Review the draft before saving it to Agent Compose.

## Improvements

- **Lighter settings design** Restore subtle borders and align Agent Compose tables, model selectors and switches with Zo's settings controls.
- **Capability-aware conversations** Keep remote model and permission controls consistent with the selected agent's capabilities.

## Bug Fixes

- **Reliable progress and recovery** Improve connection progress, interrupted runs, refresh recovery and readable upstream errors.
- **Native model IDs** Preserve the model ID returned by Agent Compose instead of adding a provider prefix that breaks model requests.
- **Complete update artifacts** Include the update ZIP, manifest and embedded update configuration alongside the installer.

## Breaking Changes

None.

## Installation

This release includes a macOS Apple Silicon (M1/M2/M3/M4) installer and an automatic-update ZIP. It is ad hoc signed and is not notarized by Apple. On first launch, macOS may require approval in System Settings → Privacy & Security.

Agent Compose runs separately. Configure its Daemon API address and Daemon API Token in Settings → Agent Compose; the management website's login token is not a daemon credential. Provider model discovery requires a compatible Agent Compose server; this repository includes the local compatibility patch in `patches/agent-compose-model-discovery.patch`.

No account credentials, server tokens or local chat history are included in the installer.
