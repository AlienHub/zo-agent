# v0.2.3 - Agent Compose History and Management

## Features

- **Remote conversation history** Browse an Agent Compose agent's runs and import completed sandbox conversations into Zo as read-only history. Restore available Pi tool calls and thinking, fall back to saved run output when a sandbox is gone, and preserve previously imported messages when remote retention removes logs.
- **Manage through Zo's own agent** A bundled Agent Compose skill and native CLI use saved server connections, credentials and SSH settings on the Zo service host. Read mode enforces a daemon RPC allowlist; configuration changes and remote execution use Zo's ordinary execution permissions. Remote sandbox agents do not inherit this management capability.

## Bug Fixes

- **Reliable remote stop** Deduplicate repeated stop requests and restored composer input, keep stop intent through reconnects, and let remote status confirm completion even if the stop response is lost. Ambiguous submissions retain their original request identity.
- **Headless management** Load bundled skills and read-only permission defaults in native agent subprocesses and standalone servers. Keep model-provider proxies from rerouting saved direct or SSH management connections.
- **Bounded management output** Reject oversized CLI output instead of reporting a successful partial result.

## Runtime Support

- Include a reproducible Pi-only Docker image recipe and offline checks. Keep the complete MCP adapter so its sibling modules and `--mcp-config` option load correctly. Existing Agent Compose servers, agent configurations and sandbox images are not changed by installing Zo.

## Installation

Includes the macOS Apple Silicon installer, update ZIP and update manifest. Users on **0.2.2** can use **Check for Updates**. Users on **0.2.0 or 0.2.1** should quit Zo and replace it manually using the DMG because those versions contain the earlier updater defect. Keep the existing Zo configuration directory to preserve connections and chats.

The app is ad hoc signed and is not notarized by Apple. Agent Compose remains a separately deployed service.
