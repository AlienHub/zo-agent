# v0.2.1 - Remote Agent Tools and Connections

## Features

- **Native remote MCP** Configure Streamable HTTP MCP services directly on Agent Compose agents, including authentication headers. Saved credentials remain on the server, shared project definitions stay intact, and conflicting edits or active runs prevent unsafe saves. (39f59278)
- **Agent Compose over SSH** Reuse the Zo server machine's OpenSSH configuration, keys and ssh-agent. Test connections in settings and automatically reconnect interrupted tunnels. (b3281d37)

## Improvements

- **Agent creation** Describe requirements alongside an editable configuration preview. Discover runtime images from the selected server, retain custom image references, and keep long image names within the dialog. (b3281d37)
- **Clear execution settings** Compose conversations show sandbox capabilities and link to native agent settings. Local permissions, folders, MCP sources, skills and model overrides are hidden where they do not apply; settings explain which execution options affect local agents. (b3281d37)

## Bug Fixes

- **Remote configuration boundaries** Reject unsupported local settings before changing remote-session metadata or history, and avoid initializing local MCP integrations for Compose runs. (b3281d37)
- **Native model IDs** Preserve model identifiers supplied by Agent Compose in model selectors. (c296d3a8)

## Breaking Changes

None.

## Installation

Includes the macOS Apple Silicon installer, automatic-update ZIP and update manifest. The app is ad hoc signed and is not notarized by Apple.

Agent Compose runs separately. Remote MCP URLs must be reachable from its sandbox. Older Pi guest images with an incomplete MCP adapter may require the compatibility image described in `docs/agent-compose-remote-mcp.md`; this release does not replace existing server images automatically.

For SSH connections, configuration and unlocked keys must be available on the machine running the Zo service. No credentials, server tokens or local chat history are included in these downloads.
