# v0.2.2 - Reliable macOS Updates

## Features

None.

## Improvements

- **Safe update handoff** Validate the release ZIP checksum, bundle identity, version, CPU architecture and code integrity before closing Zo. Save window state and flush sessions before replacing the app.

## Bug Fixes

- **macOS restart after update** Restore automatic installation for ad hoc signed macOS builds, fixing the regression that could close 0.2.0/0.2.1 without reopening the updated app.
- **Startup recovery** Keep the previous app until the new version confirms initialization and window loading. Failed or stalled startup restores and reopens the previous version; a quit timeout leaves the installed app unchanged.
- **Accurate update status** Wait for a verified download or native installer readiness. Cached ZIPs and metadata alone no longer show an update as ready, and failed checks no longer appear as “up to date”.

## Breaking Changes

None.

## Installation

**Users on 0.2.0 or 0.2.1 must download the 0.2.2 DMG and replace Zo manually once.** Those versions contain the broken updater; installing this release restores automatic updates for subsequent releases. Quit Zo before replacing it, then reopen it from Applications. Keep `~/.craft-agent` (or your configured `CRAFT_CONFIG_DIR`) so connections and chat history remain available.

Includes the macOS Apple Silicon installer, update ZIP and update manifest. The app is ad hoc signed and is not notarized by Apple. Agent Compose continues to run separately. This release does not change its configuration or sandbox images.
